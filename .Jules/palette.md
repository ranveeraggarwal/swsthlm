## 2024-09-07 - Copyable Input UX
**Learning:** Adding a click handler directly to a read-only text input containing copyable information (like a URL) significantly improves the UX for mouse users compared to requiring them to precisely click a small adjacent button, especially when paired with a visual cue like `cursor-pointer`.
**Action:** When displaying non-editable, copyable data in an `<input>`, add an `onClick` handler to copy the text to the clipboard and update the `<input>` element with `cursor-pointer` to indicate it is clickable. Ensure screen reader support by keeping the `aria-label` or explicit `<button>` for keyboard users intact.
